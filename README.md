# turniping

日本株(個別銘柄 + 日経平均 / TOPIX連動ETF)の値動きを、実際の株価データとニュースから予想し、
市場が開いているときにリアルタイムで答え合わせしながら学ぶためのアプリ。

- **モック/合成データは使わない**。株価は Yahoo Finance の公開chart APIから、ニュースはNHK/Google NewsのRSSから実際に取得する。
- 予想はルールベース(移動平均・RSI・MACD・ボリンジャーバンド・出来高・相場全体との整合性)+ニュースの簡易センチメント分析の組み合わせ。
- 予想の的中率を記録し、答え合わせを繰り返しながら「どんな時に当たりやすいか」を学べるようにしている。
- **自己学習**: 答え合わせの実績から、どのシグナルが実際に当たっていたかを定期的に振り返り、的中率の高いシグナルの重みを強め、外れの多いシグナルの重みを弱める(`/accuracy`の「学習状況」で確認可能)。
- 実際のお金は動かさないペーパートレード機能で売買を練習できる。
- **AI自動売買シミュレーション**: 予想エンジンが実際の株価だけを使い、5万円(仮想)の元手で自動的に売買したら資金がどう推移するかを検証できる(`/ai-trading`)。

## 構成

- `backend/`: FastAPI + SQLAlchemy(async) + PostgreSQL + APScheduler worker + Redis(価格のWS配信)
- `frontend/`: Next.js (App Router) + React Query + lightweight-charts

同一マシン内の `FXTradingLab/`(FX版)と同じ構成パターンを踏襲している。

## ローカル起動(Windows, Docker不使用)

前提: PostgreSQL 17がローカルで動いていること、`tools/redis/`にポータブルRedisがあること、Python 3.14(`py -3.14`)とNode 20が使えること。

### 初回セットアップ

```powershell
# 1. DB作成 (初回のみ)
psql -U postgres -c "CREATE ROLE turniping WITH LOGIN PASSWORD 'turniping';"
psql -U postgres -c "CREATE DATABASE turniping OWNER turniping;"
psql -U postgres -c "CREATE DATABASE turniping_test OWNER turniping;"

# 2. バックエンド
cd backend
py -3.14 -m venv .venv
.\.venv\Scripts\pip install -r requirements-dev.txt
copy .env.example .env
.\.venv\Scripts\python -m alembic upgrade head

# 3. フロントエンド
cd ..\frontend
copy .env.local.example .env.local
npm install
```

### 起動

```powershell
.\start-local.ps1
```

Redis・API(:8001)・worker・Next.js(:3002)の4ウィンドウが立ち上がる。
`APP_ENV=development`ではフロントのログインゲートとバックエンドの認証は無効化される。

- フロントエンド: http://localhost:3002
- API docs: http://localhost:8001/docs

## 銘柄の追加

デフォルトのウォッチリストは`backend/app/instruments_catalog.py`で管理しており、現在79銘柄
(日経平均・TOPIX連動ETFに加え、自動車・電機精密・半導体/電子部品・通信/IT・銀行・証券金融・商社・小売・医薬品・鉄鋼素材・化学・機械重工業・不動産・運輸・食品/生活必需品・エネルギー・エンタメなど主要セクターを分散してカバー、全銘柄Yahoo Financeでの取得確認済み)。
一部銘柄だけで始めたい場合は`.env`の`DEFAULT_WATCHLIST`で上書きできる。
ダッシュボード画面から証券コード(例: `9432.T`)を入力すればさらに追加でき、Yahoo Financeから銘柄名を自動取得する。

## 情報収集(常時)

- 株価: 東証の立会時間(前場9:00-11:30, 後場12:30-15:00 JST、土日祝休場)中は30秒間隔でポーリング。
- ニュース: 5分間隔で、ウォッチリスト銘柄ごとのニュースに加え、国内景気(NHK経済)・世界経済(NHK国際)・米国株式市場・FRBの金融政策・為替・原油価格・中国経済など、値動きに影響しうる世界の情報を市場が閉まっている時間帯も含めて常時収集する。
- 予想: 10分間隔でテクニカル指標+直近48時間のニュースセンチメント+出来高+相場全体(日経平均)との整合性から再計算。79銘柄は最大10件同時に並行取得する(逐次取得だと通信不調時にジョブが長時間化し、他のジョブの実行枠を奪ってしまうため)。
- 答え合わせ: 予想時刻より後に実際に価格が動いた(=市場が開いて取引された)ことを確認できてから評価する。市場が閉まったままの「値動きゼロ」を評価に使うと、下落予想が機械的に不正解、上昇予想が機械的に正解になり的中率が大きく歪むため。

## 自己学習の仕組み

答え合わせが溜まるたびに(既定1時間ごと)、各シグナル(移動平均クロス・RSI・MACD・ボリンジャーバンド・ニュースセンチメント・相場全体との整合性)が**単独で**方向をどれだけ当てられていたかを振り返り、[Multiplicative Weights(Hedge)アルゴリズム](https://en.wikipedia.org/wiki/Multiplicative_weight_update_method)で重みを更新する。的中率が高いシグナルほど重み(発言力)が増し、外れが多いシグナルほど下がる。ブラックボックスなMLモデルではなく、「どのシグナルが何%的中し、重みがいくつになったか」を`/accuracy`の「学習状況」やAPI(`GET /api/v1/predictions/strategy-weights`)で常に確認できる。

- 十分な件数(シグナルごとに既定20件)が溜まるまでは重みは既定値(1.0)のまま調整されない。
- 重みは`0.3〜2.0`の範囲にクリップし、1つのシグナルが支配的になりすぎたり、逆に発言権を完全に失って回復できなくなったりしないようにしている。
- 出来高は単体では方向を持たない(他シグナルを補強/割引するだけ)ため、学習対象には含めていない。

### バックテスト(過去の値動きによる学習の前倒し)

ライブの答え合わせだけでは、60分先の予想を市場が開いている間しか評価できないため、
十分な件数が溜まるまでに何日もかかる。そこで既定24時間ごとに、ウォッチリスト全銘柄の
過去5年分の日足を取得し、「その日までのデータだけを使って予想していたら、翌営業日に
実際どちらへ動いたか」を1日ずつ遡って計算し直す(先読みなし。予想エンジンはライブと
完全に同じ`combine_prediction`関数を使うため、学習内容とライブ予想のロジックは常に一致する)。
これを`backtest_signal_samples`テーブルに蓄積し、自己学習の再計算(`strategy_learning.recalibrate`)
はライブの答え合わせとこのバックテストサンプルの両方を合わせて各シグナルの的中率を測る。

79銘柄×5年分(数万サンプル規模)を機械的に検証できるため、ライブデータだけを待つより
遥かに早く、統計的に確からしい重み付けができる。ただし、バックテストは「翌営業日の終値」、
ライブは「60分後」という異なる時間軸の近似であることには留意(日足データしか無料で
遡って取得できないための制約)。またニュースセンチメントは過去のニュース記事を保有していない
ため、バックテストの対象には含まれない(ライブの答え合わせのみで学習される)。

## AI自動売買シミュレーション

`/ai-trading` で確認できる、手動のペーパートレードとは別の専用口座(元手5万円)。

- ルール: 直近の予想が「上昇・確信度35%以上」かつ未保有 → 1銘柄あたり上限1万円まで買う / 「下落・確信度35%以上」かつ保有中 → 全数売却。ナンピン買い増しはしない。
- 確信度の閾値(既定35%)は、prediction_engineの連続スコアリング方式における実際の確信度分布(中央値17%・90パーセンタイル34%、実測)を踏まえ、「上位1割程度の強いシグナルのみで動く」ように設定している。`AUTO_TRADER_BUY_CONFIDENCE_THRESHOLD` / `AUTO_TRADER_SELL_CONFIDENCE_THRESHOLD` で調整可能。
- 東証の立会時間中のみ、10分間隔(`AUTO_TRADER_INTERVAL_MINUTES`)で判断・発注し、評価額を記録する(資金推移グラフの元データ)。
- 売買はすべて実際の株価で約定させ、発注理由(どの予想・どの指標が根拠だったか)を記録する。
- 手数料・税金は考慮しない。単元株(100株単位)ではなく1株単位で売買する(5万円という少額でも複数銘柄に分散投資する体験ができるようにするため)。

## 注意

- 価格ポーリングのみ東証の立会時間限定。ニュース収集と予想計算は24時間動く(workerプロセスを起動している間)。
- ニュースのセンチメント判定はキーワード辞書によるシンプルな方式であり、投資判断の根拠として十分な精度は保証しない。
- ここでの「予想」は学習・検証目的であり、実際の投資助言ではない。
